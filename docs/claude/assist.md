## Explainer engine (H1b; not wired to any handler yet)

- `server/game/assist/`, pure and synchronous (no I/O, `Math.random`, `Date` or uuid; never makes a bot, never mutates `SEARCH`):
  - `seatView.js` `seatView(game, pos)`: the ONLY file that reads a GameState. A deep-frozen copy of what that seat may know: its own hand, trump, stage, `turnKey`, `currentTurn`, bids, score, the table, the contract (`BotController.buildPlayContext`) and the memory a bot in the seat would hold (`cardMemory.fromHistory` over `trickHistory` + `tableView.openTrick`), legal cards (play) or valid bids (bid). Null outside BIDDING / PLAYING. Keys pinned by `seatView.test.js`
  - `advise.js` `advise(view, {budget: 'full'|'rules', onError})`: exactly Mary's bid or card (`calculateOptimalBid` / `selectOptimalCard` with `personality 'mary'`, default search settings, a trace); `'rules'` passes `searchOptions {maxCards: 0}` (`source 'quick'` where the search would have run). A search error goes to `onError` (default: ignored), never to `SEARCH.errors` or the bots' log. Null when it is not the seat's turn
  - `explain.js` `explain(decision, view, {mode: 'help'|'tutorial', glossed})` -> `{headline, reasons (1-2), details (≤ 4), confidence, suggest, codes, gloss?}`, and `status(view)` (the off-turn line). Every reason comes from the path the bot took: the bid trace (EV curve, remove-one card attribution with `estimateOwnTricks`, make rates from `teamTrickDistribution` once the partner has bid), the terminal rule code and its facts, or the search's per-card `makes` / `sets` / `totals` over `samples` deals
  - `reasons.js`: the code -> words table (C.* contract line, L.* / F.* / D.* rule codes); `copy.js`: card and suit words, hedged rates ("usually (about 80%)", rounded to 5%), "about 1.9" tricks, "about +58" points, length caps (headline 60, reason 140, line 200), the glossary, `render(e, {style: 'rich'|'line', uses, freeUses, counted})`
- Copy rules (`copy.test.js` with `sim/lint.js` over every decision of seeded games): names only ("Bob (your partner)" on first mention, the other pair "Carol and Dan"; never team numbers, "your team", "opponents"), "suggested" and "our strongest bot", never "optimal", no gendered pronouns, no jargon (ruff, boss, EV), and no card the seat cannot see (own hand, played cards, the trump card)
- Tests: agreement with the Mary bot at every decision of 200 seeded games (`agreementA-D.test.js`, 50 games each, `testUtils/assistAgreement.js`; B-D only with `ASSIST_AGREEMENT_FULL=1`, about 2 min of CPU each: run them locally after any bot or assist change; A runs everywhere, CI included); fairness (`fairness.test.js`: a Proxy game that throws outside the read whitelist, 500 positions with the hidden hands dealt again giving byte-identical answers, 1,000 calls with Math.random / Date / uuid throwing, bot searches interleaved with /help); a real-handler game with /help at every turn for every seat identical to a plain one (`unperturbed.test.js`); `explain.test.js` (the owner-review fixtures, the plan's bid examples, forced / quick / status / glosses / onError); `perf.test.js` (/help p99 within the bot's own)
